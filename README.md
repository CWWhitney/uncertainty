# uncertainty

A collection of functions for use in assessing uncertainty. Install
using `devtools::install_github("CWWhitney/uncertainty")`

**Note:** this package is unrelated to the CRAN package
[`uncertainty`](https://CRAN.R-project.org/package=uncertainty) (Gasca-Aragon),
which *computes* uncertainty (Gaussian, Monte Carlo, Kragten). This package
*visualises* uncertainty in simulation outputs, so the two complement each
other. See [COMPARISON.md](COMPARISON.md).

Cited in: 

Luedeling E, Whitney C, Wilkes A, Aynekulu E, Rosenstock TS. Limitations of using simple indicators for evaluating agricultural emission reductions at farm level — evidence from Kenyan smallholder dairy production. Carbon Footprints. 2022;1:21. doi:10.20517/cf.2022.11
